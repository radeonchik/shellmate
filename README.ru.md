# shellmate — умный терминал

**Русский** · [English](README.md)

Пишешь, что нужно, своими словами — shellmate понимает, что сделать, показывает точную команду и
выполняет её только после твоего «y». Модель работает локально, на твоём компьютере.

```
shellmate установи обс студио          shellmate проверь, всё ли в порядке с системой
shellmate обнови систему                  shellmate почему не работает звук
shellmate верни старую версию mesa        shellmate что тормозит комп
shellmate что занимает много места на диске         shellmate в каком пакете команда convert
shellmate инфа о системе                  shellmate кто занял порт 8080
shellmate как включить hdr в hyprland     shellmate найди в интернете, когда выйдет ядро 7.3
shellmate добавь ~/Documents в источники  shellmate что у меня в заметках про роутер
sudo apt install foo 2>&1 | shellmate explain
```

- **Не пишет команды сам.** Маленькая модель только распознаёт, чего вы хотите; команды собирает
  обычный код, вы видите каждую и подтверждаете `y`. Есть журнал и `shellmate отмени`.
- **Работает локально**: модель в Ollama на вашем компьютере (под железо подбирается сама).
- **Отвечает цитатами, а не пересказом**: из официальных вики (ArchWiki, Ubuntu/Debian/Fedora Docs,
  Hyprland Wiki), из интернета или из локальных документов — дословно, со ссылками.
- **Русский и английский**: интерфейс — по языку системы (выбирается при знакомстве или
  `shellmate --lang en`), запросы понимает на обоих.

## Поддерживаемые системы

| | пакеты | ещё |
|---|---|---|
| **Arch**, CachyOS, EndeavourOS, Manjaro | pacman + AUR (paru/yay) | новости Arch перед обновлением, откат из кэша |
| **Debian**, **Ubuntu**, Mint, Pop!_OS | apt (+ Snap на Ubuntu) | откат на версию из репозитория |
| **Fedora**, RHEL, Rocky, Alma | dnf (4 и 5) | откат через dnf downgrade |

Flatpak — везде. Проверить, как помощник работает с твоей системой: `shellmate --selftest`.

## Установка

Одной командой (Arch/CachyOS, Debian, Ubuntu, Fedora):

```sh
curl -fsSL https://raw.githubusercontent.com/radeonchik/shellmate/main/get.sh | sh
```

Скрипт ставит [uv](https://docs.astral.sh/uv/) и shellmate без sudo, а git, fzf и
[Ollama](https://ollama.com) — только спросив. Старым видеокартам AMD (Polaris, Vega) ставит
Ollama с Vulkan: ROCm их не поддерживает. В конце предложит познакомиться: язык, стиль, цвет,
подбор модели под железо. Своё имя помощнику: `… | sh -s -- friday`.

Или вручную:

```sh
curl -LsSf https://astral.sh/uv/install.sh | sh          # uv (или из пакетов дистрибутива)
curl -fsSL https://ollama.com/install.sh | sh             # Ollama (на Arch: sudo pacman -S ollama-cuda)

uv tool install git+https://github.com/radeonchik/shellmate
shellmate                                                    # знакомство: язык, стиль, цвет, модель
```

Желательно: `fzf` (меню выбора) и `gio` (корзина, обычно уже есть). Своё имя помощнику:
`shellmate --alias friday` — после этого работает и `friday обнови систему`.

**Обновление:** `shellmate --update` (раз в сутки shellmate сам напомнит, если вышла новая версия).
**Удаление:** `uv tool uninstall shellmate`; настройки — `~/.config/shellmate`, кэш — `~/.cache/shellmate`,
журнал — `~/.local/state/shellmate`.

## Режимы и команды

- `shellmate` без аргументов — **диалог**: модель держится в памяти, ↑/↓ — прошлые запросы,
  понимает продолжения («поставь гимп» → «а теперь удали его», «а как это выключить?»).
- `-d` или «подумай хорошенько», «это сложная задача» — всё делает большая модель.
- `shellmate --history` / «что ты делал» — журнал; `shellmate --undo` / «отмени» — откат последнего:
  установка ↔ удаление, автозапуск вкл ↔ выкл, файл из корзины обратно, откат пакета.
- Перед обновлением — **новости дистрибутива** (пока Arch и CachyOS): новости «manual intervention»
  про установленные у тебя пакеты показываются целиком. Только новости: `shellmate --news`.
- `shellmate --install-shell` — в fish на ненайденную команду подсказывает опечатку («gti» → git)
  и пакет с этой командой. Без модели, ~0.1 с.
- `shellmate --search-setup` — поиск в интернете (ключ Tavily, 1000 запросов в месяц бесплатно).
- `shellmate --pick-model`, `--setup` (стиль), `--lang ru|en`, `--color`, `--add-docs DIR`, `-n` (показать команды,
  не выполнять), `--debug`, `--version`, `--selftest`.

Конфиг: `~/.config/<имя>/config.toml` (права 600 — там могут быть API-ключи).

## Как это устроено

### Модель не пишет команды

Она переводит запрос в JSON (`{"intent": "install", "packages": ["obs-studio"], …}`), Ollama
ограничивает вывод JSON-схемой. Всё остальное — обычный код. Свободные советы модели проходят
фильтр: строки с `rm -rf`, `dd`, `mkfs`, `chattr`, `chmod -R` и т. п. вырезаются.

### Две модели: быстрая и внимательная

По умолчанию всё делает `model` (bonsai-2:4b). `big_model` (bonsai-2:9b) подключается, только когда
быстрая не уверена. Неуверенность определяет не сама модель, а:
- **вероятности токенов** (Ollama `logprobs`): колеблется в действии или в имени пакета;
- **проверки кодом**, ловящие уверенные ошибки: имя пакета не похоже на написанное («обсидиан» →
  obs-studio), «удали» в запросе при действии «установить», запрос не понят;
- для цитат — вероятность меток «ответ/по теме».

| (`eval/cascade_eval.py`, 143 запроса, 50 трудных) | всего | трудные | на 9B | время |
|---|---|---|---|---|
| только 4B | 92% | 80% | — | ~0.5–0.7 с |
| только 9B | 98% | 96% | 100% | ~1.5–1.7 с |
| каскад | 98% | 94% | 22% | ~0.7–0.9 с |

### Ответы цитатами (`evidence.py`)

1. Текст режется на предложения с разделом страницы («HDR › Hyprland»); команды и блоки кода
   после «…:» прицепляются к предложению.
2. Код отсекает предложения про *другую* программу того же рода: Sway/KDE на вопрос про Hyprland,
   apt/dnf на вопрос про Arch (контекст по умолчанию — твой дистрибутив), GDM на SDDM.
3. Модель выбирает до 5 номеров (JSON-схема разрешает только существующие), потом отдельно
   оценивает каждую цитату: ответ / по теме / мимо.
4. Показывается дословно, перевод — по предложению с оригиналом; нет ответа — так и сказано.

Источники по порядку: **избранные вики** для твоего дистрибутива (у каждой свой поиск, не зависящий
от поисковиков) → **интернет** (Tavily → Brave → свой SearXNG → DuckDuckGo, кэш на сутки) →
объяснение моделью с пометкой «без источников, может ошибаться».

### Код

| файл | что делает |
|---|---|
| `backends/` | pacman / apt / dnf: поиск, установка, откат, «чей файл», чистка, новости |
| `packages.py` | поверх бэкенда: Flatpak, Snap, ранжирование, подбор по написанию |
| `router.py` | промпт, примеры, схема → `Intent`; «сомнения» для каскада |
| `evidence.py`, `rag.py`, `trusted.py`, `web.py`, `docs.py` | цитаты, вики, поиск, документы |
| `system.py`, `skills_system.py` | сервисы, журнал, процессы, железо, сеть (только чтение) |
| `errors.py` | словарь ошибок pacman / apt / dnf / snap |
| `i18n.py` | язык интерфейса: `t("по-русски", "in English")` рядом в коде |
| `cli.py` | точка входа, подтверждения, журнал, отмена, диалог |
| `ui.py` | анимация, панели, темы, меню на fzf |

## Разработка

```sh
git clone https://github.com/radeonchik/shellmate && cd shellmate
./install.sh                    # editable: правки в коде сразу работают
python3 -m unittest discover -s tests
python3 -m shellmate --selftest
uv run eval/run_eval.py bonsai-2:4b -v              # распознавание запросов (нужна Ollama)
uv run eval/cascade_eval.py bonsai-2:4b bonsai-2:9b # калибровка каскада
uv run eval/quotes_eval.py --compare bonsai-2:4b    # качество цитат
```

CI (`.github/workflows/test.yml`) гоняет тесты на Python 3.10 и 3.13, `--selftest` в контейнерах
Arch, Debian 12, Ubuntu 22.04/24.04 и Fedora и установщик одной командой под dash.

**Новая версия:** поднять `version` в `pyproject.toml`, дописать `CHANGELOG.md`, затем
`git tag v0.3.0 && git push --tags` — workflow `release.yml` создаст релиз, у пользователей появится
подсказка про `--update`.

Новая ошибка → `Known(...)` в `errors.py` (текст на русском и английском). Новый интент → `INTENTS` и примеры в `router.py`, метод с
тем же именем в `App` или `skills_*.py`. Новый дистрибутив → класс в `backends/` и строка в
`backends/__init__.py`. Любое сообщение пользователю — через `t(ru, en)`.
